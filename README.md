# RBO — Rilop BackOffice

Backoffice interno da Rilop (clientes, contratos de créditos, tickets de assistência). React + Vite, Supabase, Vercel.

```bash
npm install
cp .env.example .env.local
npm run dev
```

**Documentação completa:** [`manuals/instructions.md`](manuals/instructions.md) — alojamento, base de dados, permissões, edge functions, deploy e runbook.
